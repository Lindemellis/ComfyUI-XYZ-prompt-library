# 图片画廊（Image Gallery）

[English](README.md) | **中文** · [← 返回主 README](../README_zh.md)

浏览与管理你的 ComfyUI 图片**和视频**——自动索引，支持筛选、打标签、批量操作和元数据查看。

## 打开

点击 ComfyUI 顶栏的 **Open XYZ Gallery**（图片图标）。首次打开时会扫描你的 `output` 和 `input` 目录，并在后台建立缩略图索引。

## 浏览

### 筛选（左侧面板）

| 筛选 | 说明 |
|---|---|
| 文件夹 | 选择文件夹，可选是否包含子文件夹 |
| 收藏 | 只看已收藏的图片 |
| 标签 | 带有指定标签的图片（从你的库自动补全） |
| 模型 | 按 checkpoint 模型筛选 |
| 提示词 | 在提示词里做关键词搜索 |
| 日期范围 | 按文件修改时间筛选 |
| 媒体类型 | 两个复选框：图片 / 视频。两个都不勾等于两个都勾（显示全部） |

可按时间、文件名、大小或文件夹排序（升序 / 降序）。

### 视图模式

- **Grid（网格）** —— 缩略图卡片。
- **Compact（紧凑）** —— 图多时的密集缩略图。
- **Line（行）** —— 分组行（按大小 / 日期 / 首字母）。
- **Detail（详情）** —— 单张图片的完整元数据（点击图片打开）。

## 视频

`.mp4` / `.webm` / `.mkv` / `.mov` / `.m4v` 会和图片一起被索引，用的是同一套详情页——右侧的
收藏、标签、删除、生成信息完全一致，只是宽高旁边多了时长。

- **网格** —— 缩略图是视频里抽的一帧（取 10% 处，上限 1 秒；不取第 0 帧，因为生成的视频常常是黑场开头）。
  右下角显示时长，有声的会带一个 ♪。鼠标停在卡片上会静音播放预览。
- **播放器** —— 播放/暂停、进度条、±5 秒、**逐帧步进**、音量、倍速（0.25×–2×）、循环。
- **保存当前帧** —— 把当前画面存成 PNG，可以直接拿去当参考图或送进 Krita。
- **生成信息** —— ComfyUI 写进 mp4 的 workflow 和 PNG 里的是同一份，所以提示词、模型、种子
  照常显示。

两个限制，都是有意为之：

- **视频不能发送到 Krita**（Krita 没有视频图层），所以这个按钮在视频上不显示。
- **视频只能原样下载**。下载设置里那两个复选框是在改写 PNG 的文本块，对 mp4 没有对应操作。

> **一次生成出两个 mp4？** ComfyUI 的视频工作流常常同时输出一个无声的 `X.mp4` 和一个带声的
> `X-audio.mp4`。画廊**只收录带声的那个**，否则每条生成都会在网格里出现两次。要两个都显示的话，
> 在 `gallery_data/gallery_config.json` 里把 `video_audio_twin_suffixes` 设成 `[]`。

## 标签

- 在详情页增删标签。
- 对选中的图片批量打标签。
- 收藏和标签会镜像写入 PNG 的元数据，随文件一起携带。

## 批量操作

1. 选中多张图片。
2. 在批量栏选择操作：移动、删除、收藏或打标签。
3. 画廊会做预检（如命名冲突）并显示进度。
4. 确认后执行。

## 设置

在画廊的 **Settings** 视图：

- **Theme（主题）** —— 深色 / 浅色。
- **Download（下载）** —— 通过下载选择器决定下载时包含什么（如带元数据）。仅对 PNG 生效。
- **Video（视频）** —— 卡片 hover 预览、打开时自动播放、默认循环、默认静音。只保存在本机浏览器里。
- **Filters（筛选项）** —— 选择显示哪些筛选控件。
- **Image metadata（图片元数据）** —— 重新读取生成信息不全的文件。工作流解析变强后（比如现在能
  认出 `SamplerCustomAdvanced` 这类图），点一次就能把老图缺的模型/提示词补回来。
- **Developer mode（开发者模式）** —— 额外的调试信息。

## 文件夹

- 默认根目录是 ComfyUI 的 `output` 和 `input`。
- 可添加自定义文件夹；在树中创建子文件夹、重命名、移动。

## 常见问题

**图片不显示？** 检查文件夹设置，或触发一次重新扫描。

**视频不显示？** 视频要靠 PyAV 读取（ComfyUI 自带 `av`，正常不用管）。如果整个 ComfyUI 环境里
没有 `av`，视频会被静默跳过，图片不受影响。另外确认筛选里的「视频」复选框没被取消。

**生成信息是空的？** 到 **Settings → Image metadata** 点「Re-read missing metadata」。它会在后台
重读那些字段不全的文件。

**缩略图一开始很慢？** 首次查看时生成，之后缓存为 `.webp`。

**数据在哪里？** 在 `gallery_data/`（已 gitignore）：索引数据库和缩略图缓存。除了收藏/标签的元数据镜像外，原始图片不会被修改。
