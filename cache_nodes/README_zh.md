# Cache Slot(缓存槽)

把图片存进一个命名的槽,下次运行时取出来。

| 节点 | 分类 | 用途 |
|---|---|---|
| **XYZ Cache Slot Write** | `XYZNodes/Cache` | `IMAGE` → 槽 |
| **XYZ Cache Slot Read** | `XYZNodes/Cache` | 槽 → `IMAGE` + `width`/`height` |

**和 Krita 无关。** 这是纯 ComfyUI 的跨运行中间结果交接方式 —— 存一张底图、存一次放大的结果 —— 免得
每次想动下一步都要把整条链重跑一遍。Krita 联动是另一条交接路线,两者并存,用途不同。

## 工作方式

一个槽就是 **`output/xyz_cache/<槽名>/`** 下的一个文件夹,里面只放一张图。往同一个槽写入会**替换**
原来的那张。整个模型就这么简单 —— 就是你现在手工在做的「一个文件夹放一张图」,节点化而已。

槽名只接受字母、数字、`.`、`-`、`_` —— 任何可能爬出缓存目录的字符都不行。

## 怎么用

```
… → XYZ Cache Slot Write   (slot: "base")
```
跑一次。然后在**之后的**某次运行里 —— 换个工作流、换一天:
```
XYZ Cache Slot Read  (slot: "base") → 放大 → …
```

Read 节点的下拉框列出已存在的槽。**当前这次 ComfyUI 会话里**新写的槽不会立刻出现在列表里(要刷新页面),
但你**直接手打槽名也能用** —— 节点不会因为没见过这个名字就拒绝它。

每次运行都会重新检查文件,所以你在 ComfyUI 之外改了槽里的图,会立刻生效,而不是被执行缓存挡住。
